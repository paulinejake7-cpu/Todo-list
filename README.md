# Туду-лист на Python

Настольное приложение (tkinter): задачи и подзадачи, категории по срокам, дедлайны, напоминания, поиск, связи между задачами, описания, отчёты о завершении и синхронизация с Google Диском.

## Запуск

```
pip install -r requirements.txt     # Google Диск и значок в трее (оба необязательны)
python todo_app.py
```

Для самого списка задач ничего устанавливать не нужно: достаточно Python 3.10+ с tkinter.
(На Linux tkinter иногда ставится отдельно: `sudo apt install python3-tk`.)

Данные хранятся в `~/.todo_app/tasks.json`. Другую папку можно задать переменной окружения `TODO_APP_DIR`.
Файлы, созданные прошлой версией, подхватываются автоматически.

## Что умеет

- **Категории**: Сегодня / На этой неделе / В этом месяце / В этом году (вкладки), плюс вкладка «Архив» для закрытых задач. В названии вкладки — число незавершённых задач и, если есть просроченные, значок ⚠ с их числом.
- **Подзадачи**: выберите задачу и нажмите «+ Подзадача». Любая вложенность, подзадача относится к категории родителя и переносится вместе с ним.
- **Завершение**: кнопка «Завершить» открывает окно для отчёта (или «Провалена», см. ниже). Завершённая задача перечёркивается и серится, «Вернуть в работу» снимает отметку.
- **Описание и отчёт**: поля справа, сохраняются автоматически при переключении на другую задачу (или Ctrl+S).
- **Связи**: «Связать…» соединяет две задачи (связь двусторонняя). Двойной щелчок по связанной задаче переходит к ней, даже в другую категорию.

### Архив

Выполненные и проваленные задачи не висят в категориях вечно: через заданное время они уходят во вкладку **«Архив»**. По умолчанию это **на следующий день**: закрыли задачу сегодня, она остаётся в списке до конца дня (чтобы вы видели, что сделано), а завтра её там уже нет.
- В архиве задачи сгруппированы по месяцам закрытия, свежие сверху; рядом указаны прежняя категория и дата закрытия. Архивную задачу можно открыть, прочитать отчёт или причину провала, найти поиском.
- **Вернуть в работу** (кнопка в карточке) достаёт задачу из архива обратно в её категорию.
- Срок настраивается в окне **«Вид» → «В архив»**: сразу после завершения / на следующий день / через 3 дня / через неделю / через месяц / никогда.
- Если у закрытой задачи остались открытые подзадачи, она остаётся в категории, пока не закрыты все подзадачи.
- Подзадачи уходят в архив вместе с основной задачей.
- Ничего не удаляется и не меняется: архив только способ показа. Поэтому **отчёт за период** учитывает и архивные задачи, а синхронизация с Google Диском работает как раньше. Настройка срока хранится локально, как шрифт и тема.

### Перенос между категориями

Задачу можно перенести (например, из «Сегодня» в «В этом месяце») тремя способами:
- **Правая кнопка мыши** по задаче в списке → выбрать категорию.
- Кнопка **«Перенести в… ▾»** под списком.
- Выпадающий список **«Категория»** в карточке задачи: перенос происходит сразу после выбора.

Задача переносится вместе со всеми подзадачами, связи и отчёты сохраняются, откроется вкладка новой категории. Если переносите **подзадачу**, она отделяется от родителя и становится самостоятельной задачей в выбранной категории (перед этим приложение спросит подтверждение).

### Провал задачи

Кроме «Завершить» в карточке есть кнопка **«✘ Провалена»**: приложение спросит причину или выводы (можно оставить пустым) и закроет задачу как проваленную. В списке такая задача отмечена ✘ и красная, причина лежит в поле «Отчёт». Проваленную (как и выполненную) задачу можно вернуть в работу, а выполненную можно перевести в проваленные. Напоминания по проваленным задачам не приходят.

### Отчёт за период

Кнопка **«📊 Отчёт»** вверху. Выберите период (день, неделя, месяц, год, всё время) и листайте стрелками ◀ ▶ (например, прошлый месяц). Окно показывает:
- сколько задач в периоде, из них **выполнено**, **провалено** и **в работе** (в штуках и в процентах), цветную полосу пропорций;
- успешность: сколько выполнено из закрытых задач, и сколько задач в работе уже просрочено;
- таблицу по категориям;
- список проваленных задач с датой и причиной (двойной щелчок открывает задачу).

Флажок «Считать подзадачи» включает подзадачи в подсчёт (по умолчанию считаются только основные задачи). Цифры обновляются сразу, пока окно открыто.

В период задача попадает **по дедлайну**; если дедлайна нет — по дате закрытия (для закрытых задач) или по дате создания (для открытых). Категория («Сегодня», «В этом месяце» и т. д.) на это не влияет: она показывает, когда вы планируете заняться задачей, а не к какому периоду она относится.

### Дедлайны

Поле «Дедлайн» в карточке. Формат: `05.11.2026`, `05.11` (текущий год), `завтра`, `сегодня`, `+3` (через 3 дня). Есть кнопки «Сегодня», «Завтра», «+7 дн.», «✕».
Кнопка **📅** рядом с полем открывает календарь: листайте месяцы стрелками ◀ ▶, нажмите на число, и дедлайн установлен. Сегодняшний день обведён рамкой, уже выбранный подсвечен. **Прошедшие дни серые и недоступны для выбора**, назад по месяцам листать нельзя. Календарь написан на стандартном tkinter, дополнительных библиотек не нужно. Поле можно по-прежнему заполнять вручную: там ограничения нет (чтобы, например, можно было записать задачу задним числом), так что прошедшие даты запрещены только в календаре.
В списке рядом с задачей показывается 📅 с датой. Просроченные задачи красные, задачи со сроком «сегодня» оранжевые. Внутри категории задачи сортируются по дедлайну (без дедлайна — в конце, завершённые — внизу).

### Напоминания

Поле «Напомнить»: `05.11.2026 18:30`, `05.11 18:30`, `завтра 9:00`, `18:30` (сегодня; если время уже прошло — завтра). Есть кнопки «Через 1 ч» и «Завтра 9:00».
В списке задача помечается ⏰. В указанное время появляется окно поверх других с кнопками «Открыть задачу», «Через 10 мин», «Через 1 ч», «Закрыть».

Важно: напоминания работают, пока приложение запущено (проверка раз в 30 секунд). Если время наступило, когда приложение было закрыто, напоминание покажется сразу после следующего запуска. Для завершённых задач напоминания не показываются.

### Поиск

Строка «Поиск» вверху (Ctrl+F — перейти в неё, Esc — очистить). Ищет по названию, описанию и отчёту во всех категориях, регистр не важен, нужно совпадение всех введённых слов. У найденной подзадачи показывается и её родитель. Флажок «Скрыть завершённые» убирает выполненное. Если вы переходите по связи к задаче, скрытой поиском, фильтр сбрасывается.

### Трей

Если установлены `pystray` и `Pillow` (есть в requirements.txt), в системном трее появляется значок приложения.
- Крестик окна и кнопка «В трей» прячут окно в трей; приложение продолжает работать, **напоминания приходят** (окно поверх всех и всплывающее уведомление).
- Клик (двойной клик) по значку или пункт «Открыть» возвращает окно. Пункт «Выйти» в меню значка, кнопка «Выход» и Ctrl+Q закрывают приложение полностью.
- Без `pystray` или если трей недоступен, всё работает как раньше: крестик просто закрывает приложение.

На Windows трей работает из коробки. На Linux нужна поддержка значков в панели (AppIndicator / расширение для GNOME). На macOS `pystray` может плохо уживаться с tkinter; если значок не появился, приложение просто работает без трея.

### Вид: шрифт и тема

Кнопка «Вид» вверху открывает окно настроек. Изменения применяются сразу, без перезапуска, и запоминаются.
- **Шрифт и размер** (8–32): меняются во всём приложении — списке, карточке, кнопках, окнах напоминаний.
- **Тема**: «Как в системе» (родное оформление ОС), «Светлая» и «Тёмная». Светлая и тёмная красят все элементы, включая вкладки, поля, списки и полосы прокрутки; цвета просроченных и сегодняшних задач подстраиваются под тему.
- «По умолчанию» возвращает системный шрифт и тему.

Настройки лежат в `~/.todo_app/settings.json` и **не синхронизируются** с Google Диском: на каждом компьютере можно выбрать своё. Окна, уже открытые в момент смены темы (например, окно напоминания), перекрасятся только при следующем открытии.

## Google Диск

Приложение хранит копию списка в файле `todo_tasks.json` на вашем Диске. Кнопка «Синхронизировать» скачивает этот файл, объединяет с локальными задачами (для каждой задачи побеждает более поздняя правка, удаления тоже синхронизируются) и загружает результат обратно. Так можно работать на нескольких компьютерах. Дедлайны и напоминания синхронизируются вместе с задачами.

Один раз нужно получить `credentials.json`:

1. Откройте https://console.cloud.google.com/ и создайте проект.
2. «API и сервисы» → «Библиотека» → включите **Google Drive API**.
3. «API и сервисы» → «Экран согласия OAuth»: тип «Внешний», добавьте свой e-mail в тестовые пользователи.
4. «Учётные данные» → «Создать учётные данные» → «Идентификатор клиента OAuth» → тип **«Приложение для ПК»**.
5. Скачайте JSON, переименуйте в `credentials.json` и положите в `~/.todo_app/` или рядом с `todo_app.py`.

При первой синхронизации откроется браузер для входа в аккаунт Google; после этого создаётся `token.json`, и вход больше не нужен.
Используется доступ `drive.file`: приложение видит только созданный им файл, а не весь ваш Диск.

Время напоминаний хранится как локальное. Если вы синхронизируете компьютеры в разных часовых поясах, напоминание сработает по местному времени каждого из них.

## Файлы

- `todo_app.py` — интерфейс
- `tray.py` — значок в трее
- `datepicker.py` — календарь для выбора дедлайна
- `store.py` — хранение задач, даты, поиск, напоминания, слияние
- `gdrive_sync.py` — работа с Google Drive API
